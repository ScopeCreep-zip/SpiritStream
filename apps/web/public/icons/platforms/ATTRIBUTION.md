# Bundled platform-logo attribution

The monochrome SVG marks in this directory are service logos used to identify
streaming platforms in SpiritStream. They are bundled in the repo (not fetched
at runtime) because SpiritStream is a local-first app.

## Source: Simple Icons (CC0 1.0)

| File | Platform | Simple Icons slug |
|------|----------|-------------------|
| `kick.svg`       | Kick       | kick       |
| `rumble.svg`     | Rumble     | rumble     |
| `tiktok.svg`     | TikTok     | tiktok     |
| `bilibili.svg`   | Bilibili   | bilibili   |
| `niconico.svg`   | niconico   | niconico   |
| `onlyfans.svg`   | OnlyFans   | onlyfans   |
| `streamlabs.svg` | Streamlabs | streamlabs |

All files are taken unmodified from [Simple Icons](https://simpleicons.org),
released into the public domain under
[**CC0 1.0 Universal**](https://creativecommons.org/publicdomain/zero/1.0/).

Brand logos are trademarks of their respective owners and are used here solely
to identify the corresponding service (nominative use). Per Simple Icons'
policy, the CC0 release covers the SVG path data; trademark rights remain with
each brand.
