# Shared JS/TS packages

Workspace members consumed by the React frontend (`apps/web`) and the Tauri shell (`apps/desktop`, future mobile targets).

| Package | Purpose |
|---|---|
| `types/` | TypeScript types generated by `ts-rs` from `crates/core` Rust models. Auto-regenerated; do not edit by hand. |
| `api-client/` | Typed `ApiClient` interface plus `HttpClient` implementation generated by `@hey-api/openapi-ts` from the server's OpenAPI spec. The only way the frontend talks to the backend. |
| `validation/` | JSON Schemas extracted from utoipa for runtime form-level validation (decorative; backend is the source of truth). |
| `ui/` | Shared React UI primitives (`<PasswordInput>`, `<FormField>`, `<ConfirmDialog>`, `useFormState`, `useFormValidation`). Used by the web app and the Tauri shells (desktop + mobile) — one component set, three shells. |

Generated packages (`types`, `api-client`, `validation`) commit their build output so frontend builds work offline; CI verifies regeneration matches what's committed.
